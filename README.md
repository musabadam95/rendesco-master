### Running Locally

From the root folder, run `npm install` to install all required dependencies.
Ensure that the component and the types have been added to the web application.
To use the component, call <GreenEnergyPercentage> into the HTML

You can also use the current web application to view the component
Run npm run dev to start the app under the local server
Open http://localhost:5173/ in your preferred browser (tested on Microsoft Edge)
